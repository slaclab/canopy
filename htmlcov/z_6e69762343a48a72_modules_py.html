1"""The canonical set of module scopes an API key can be restricted to. 

2 

3Mirrors the mount points in ``canopy.main`` plus ``core`` for the parent app's 

4own routes (``/health``, ``/v1/api-keys``). Hardcoded rather than derived from 

5``main.py`` at import time — ``main`` imports ``canopy.core.security``, so the 

6reverse import would be circular — but ``tests/canopy/core/test_modules.py`` 

7asserts this set equals the actual mounts, so an eleventh sub-app cannot be 

8added without either updating this set or failing CI. 

9""" 

10 

11WILDCARD = "*"

13JOBS = "jobs" 

14"""Any module-scoped key is implicitly allowed here: a job's status poll 

15(``GET /jobs/v1/{id}``) carries no data beyond what the enqueuing route 

16(squirrel, converter, ...) already returned, so gating it behind an explicit 

17``+jobs`` would just break polling for every module that hands out job ids."""

36def split_modules(modules: set[str]) -> tuple[frozenset[str], frozenset[str]]: 

37 """Partition a set of module names into (recognized, unrecognized). 

38 

39 Shared by ``EnvKeyRegistry`` and the key-management service, which parse 

40 the same ``@module+module`` shape but disagree on what to do with an 

41 unrecognized name: the env layer warns and drops it (a typo in a static 

42 key must not take an otherwise-good entry down), the service layer raises 

43 (a typo in an HTTP/CLI request is a mistake the caller can fix on the 

44 spot). That difference stays with each caller; this only does the 

45 classification. ``WILDCARD`` counts as recognized, and its presence 

46 collapses the recognized set down to just ``{WILDCARD}``. 

47 """ 

48 unknown = frozenset(modules) - MODULES - {WILDCARD} 

49 known = frozenset(modules) - unknown 

50 if WILDCARD in known: 

51 known = frozenset({WILDCARD}) 

52 return known, unknown

55def tag_module(app, module: str) -> None: 

56 """Attach ``module`` to an ASGI app instance, read back via ``request.app.state`` 

57 / ``websocket.app.state`` in ``canopy.core.security``. 

58 

59 Deliberately not derived from the URL: a mounted sub-app's own 

60 ``scope["root_path"]`` is *proxy prefix + mount path* (Starlette appends the 

61 mount to whatever root_path it was already given), so behind a path-prefixed 

62 ingress (``uvicorn --root-path /canopy``) parsing it back apart is fragile — 

63 it would have returned ``canopy/hare`` instead of ``hare``. Each app carries 

64 its own module tag instead, independent of how anything in front of it 

65 rewrites the path. 

66 """ 

67 app.state.canopy_module = module

70def module_for_app(app) -> str: 

71 """The module tag ``tag_module`` attached to this ASGI app instance.""" 

72 return app.state.canopy_module
